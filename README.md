# 龙蛋物语 · 旅行者手册

一个跑团用的**单人角色卡 + 旅行记录**工具。纯静态网页 —— 无需安装、无需服务器、不需要登录。

> ⚠️ **非商业性个人跑团辅助工具，仅供学习交流使用。**
> 《龙蛋物语》规则书的著作权归原作者及出版方所有，本项目与官方无关，请支持正版。
> 详见 [DISCLAIMER.md](DISCLAIMER.md)。

## 直接使用

打开 GitHub Pages 地址即可（无需安装任何东西）。

**最近更新**：[2026-10-20 更新记录](CHANGELOG.md) —— 药草效果联动、药师技能、副业系统、工坊（修理 / 物品制造）。

## 功能

| 模块 | 说明 |
|---|---|
| **车卡** | 8 步制卡、能力值派生、异常状态联动 |
| **背包 / 容器** | 大型容器限制、容量计算、散装道具、驮货动物 |
| **药草保质期** | 跟游戏时钟走，24 小时 / 药草瓶 7 天，过期提醒 |
| **药草效果** | 使用药草会真的作用到角色：回 HP、解异常状态、加判定、减 MP 消耗 |
| **药师技能** | 治疗 / 应急处理 / 药草采摘，自动掷骰与结算 |
| **副业** | 农民从 11 项技能里选 1 项，判定 -1 |
| **工坊** | 修理（耐久恢复）/ 物品制造，按定价查目标值，算材料费与耗时 |
| **工坊记录** | 独立于金币账本，记录每次修理 / 制造的判定与结果 |
| **商店** | 生意兴隆判定、带特征购买、容器适配 |
| **每日补给** | 食物与水的消耗，缺粮缺水累计减值（时间可回退） |
| **判定器** | 状态 / 移动 / 方向 / 野营，自动汇总全部减值，可手动改结果 |
| **血条蓝条** | 战斗快速记账，与咒语书同一份数据 |
| **咒语书** | 已学咒语、季节魔法、MP 联动 |
| **手账 / 地图** | 跑团记录与冒险地图 |
| **马车** | 车型、房间、家具摆放 |
| **图鉴** | 道具、药草、魔法、职业、技能、旅行规则速查 |
| **存档** | 多角色切换、一键全量备份 / 恢复 |
| **主持人导出** | 导出旅行者状态快照 / 全队状态，给带团的人看 |
| **打印** | 一键把角色卡排成 4 页 A4 |

## 数据保存位置

所有数据存在**你自己的浏览器里**（localStorage + IndexedDB），不上传任何服务器。

- 换浏览器 / 清理浏览器数据 / 换网址 → **数据会丢**
- 请定期用首页的「📦 一键导出全部数据」备份
- 换设备时用「📥 导入全量备份」恢复

## 版本更新

- 更新不会清掉你的角色数据（新增字段都会自动迁移）
- 但更新前仍建议先导出一份备份
- 完整变更记录见 [CHANGELOG.md](CHANGELOG.md)

## 技术说明

- 纯静态：HTML + CSS + 原生 JavaScript（无框架、无构建步骤）
- 数据文件：`js/data/`（道具、魔法、规则）
- 核心逻辑：`js/core/`（状态、背包、时钟、判定、药草、技能、工坊、存档、备份）
